# Python Practice Tasks (112 Foundation-Level Programs)

A curated collection of 112 standalone Python programs solving fundamental algorithmic challenges, ranging from basic operators to advanced nested pattern generation.

---

## 📚 Curriculum Breakdown

### 1. Basic Operators & I/O (Tasks 001 – 010)
* Arithmetic operations, circle area, simple interest, temperature conversion, divisibility checks, relational comparisons, character type classification.

### 2. Bitwise Operations (Tasks 011 – 015)
* Parity checking with bitwise AND (
 & 1), XOR variable swap, bitwise shifts (<<, >>), K-th bit detection, set bits counting (Kernighan's method).

### 3. Conditionals & Decision Making (Tasks 016 – 042)
* Leap years, multi-variable comparisons, ticket pricing, age classification, time greetings, login validation, grade ladders, day of week, electricity slab billing, triangle classification, match-case calculator, quadratic equation roots, quadrant detection, Armstrong numbers, overtime pay, ATM transactions, clock hand angles, scholarship qualification.

### 4. Loops & Number Theory (Tasks 043 – 074)
* Forward/reverse loops, even/odd series, natural number sums, digit extraction and counting, integer reversal, palindromes, Happy numbers, factorials, prime testing, GCD/HCF, LCM, Fibonacci series, harmonic series, power functions, generalized Armstrong numbers, perfect numbers, base conversions (decimal $\\leftrightarrow$ binary), Taylor sine series.

### 5. Recursion (Tasks 075 – 077)
* Recursive palindrome validation, recursive vowel counting, dual-direction recursive sequences.

### 6. Nested Loops & Patterns (Tasks 078 – 112)
* Right-angled and inverted star triangles, centered and inverted pyramids, diamond patterns, hollow rectangles/triangles, hourglass patterns, Floyd\'s triangle, Pascal\'s triangle, number pyramids, alternating binary triangles, alphabet triangles and centered pyramids, butterfly patterns,  \\times N$ spiral number matrices, heart shapes, squares with marked diagonals.
